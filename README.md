# BloxdPacks
CLI tool to install bloxd.io texture packs written in [go](https://golang.org)

Beta version for now!

# Install
## Windows
Install [scoop](https://scoop.sh)
then run this:
```text
scoop bucket add fgxd https://github.com/fg-xd/myscoop
scoop install fgxd/bloxdpacks
```
then run to test if installed:
```text
bloxdpacks --version
```
## MacOS and Linux
Install bloxdpacks binary from [releases](https://github.com/fg-xd/bloxdpacks/releases)
Move it to /usr/local/bin and add execution rights (`chmod +x bloxdpacks`)
### Quick Install Command
```bash
mv ~/Downloads/[linux-or-mac]-bloxdpacks /usr/local/bin/bloxdpacks
chmod +x /usr/local/bin/bloxdpacks
```
